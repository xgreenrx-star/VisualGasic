# Games & Physics

Game and physics demo projects.

## Overview

Sample game prototypes and physics simulations demonstrating VisualGasic integration with Godot's physics engine and node system.

## Projects

| File | Type | Purpose |
|------|------|---------|
| `pong.vg` | Game | Classic Pong implementation |
| `breakout.vg` | Game | Brick-breaker game |
| `physics_*.vg` | Physics | Physics engine experiments (gravity, collision, rigidbody) |

## Running

1. Open the `.vg` file in Godot's script editor
2. Run via Script Debugger (F5)
3. Follow on-screen instructions for gameplay

## Notes

- Physics demos use Godot 4.6+ built-in physics (PhysicsBody2D, RigidBody2D)
- Requires VisualGasic 5.2+
