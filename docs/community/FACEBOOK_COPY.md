Visual Gasic is a real programming language for Godot — VB6-style syntax (`Sub` / `Dim` / `End If`) with a C++ compiler behind it, not a toy interpreter.

Most languages optimize the **person typing**. We optimize the **person reading** — especially when AI helped write the first draft and you need to verify it quickly. That shift happened before: assembly → C, manual memory → garbage collection. Each time, critics said developers would stop understanding systems. Each time, the win went to teams that adopted the abstraction **and** built tests, debuggers, and review discipline around it.

LLMs are not deterministic like compilers — so blind trust is out. Explicit syntax, static types, and Godot-native tooling are in. Public beta on Linux and Windows; honest benchmarks on GitHub (runtime **and** compile time).
