VisualGasic 5.7.0 Beta 3 is out.

This one is a compiler and sample update on the 5.7 public beta. On Error
Resume Next actually continues after the handler. NodePath, StringName, and
RID construct. Godot constants and enums such as Vector2.UP, FileAccess, and
Key.KEY_ESCAPE fold instead of coming back null. ClassDB static calls like
FileAccess.open compile. Dictionary keys and packed mesh loops no longer
corrupt buffers. Select Case jump tables keep every case on Windows release
builds.

Ash Meridian Part 1 is further along in the examples download: the yard and
campaign run in Visual Gasic, Black Channel is a developer flight test, and
the Trace Cycle vault kit is in-tree. Normal Play is unchanged. A video of
that game is coming on YouTube when it is ready. It is not in this post yet.

Releases will keep slowing down. We are out of funds and will concentrate
on other projects. We will still put out the occasional release and bug fix.
We still intend a stable v6.0 early next year. If you have a specific bug
or a feature request, please send it. Those will be reviewed, and they are
welcome.

Downloads: Linux and Windows installers, an unsigned Intel/Apple Silicon Mac
setup, offline bundles, and a Godot Asset Library addon ZIP. Back up your
project and replace the whole addon. The store listing may lag until it is
approved.
