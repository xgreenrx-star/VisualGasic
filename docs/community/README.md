## Posting checklist

1. Read the draft once more out loud. Cuts feel different when you hear them.
2. Check that all repo links resolve on `main` (not a feature branch).
3. Post during a window when you can respond to comments for 4-6 hours.
   The first hour decides whether the thread gets traction.
4. After posting, link back to the thread from the corresponding draft file
   in a follow-up commit so future readers can see how it landed.
