## Full version

VisualGasic needs funding to keep moving at the pace the project deserves.

This is an independent open-source project focused on a specific problem: AI can generate code quickly, but humans still have to read, audit, and trust it. VisualGasic is built around that reality. It aims to make AI-generated code more readable, more explicit, and easier to verify.

The project is already real: compiler, runtime, Godot integration, documentation, examples, and active work toward v6.0. What limits progress now is not ideas. It is sustained development time and the ongoing cost of the tooling required to build and maintain it at speed.

If VisualGasic matters to you, funding helps directly.

Support goes toward:
- language and runtime work
- Godot IDE integration
- docs and tutorials
- proven working examples
- release engineering
- AI tooling costs used during development

Ways to support:
- GitHub Sponsors: https://github.com/sponsors/xgreenrx-star
- Patreon: https://patreon.com/visualgasic

If you want to help v6.0 arrive faster and stronger, this is the lever.
