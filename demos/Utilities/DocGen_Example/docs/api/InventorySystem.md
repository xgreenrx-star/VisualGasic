# InventorySystem

**Type:** Module &nbsp;|&nbsp; **File:** `res://InventorySystem.vg`

InventorySystem — A reusable item inventory manager.

Provides Add, Remove, Find, and Sort operations on a collection
of inventory items.  Designed for RPG or shop-style games.

**Example:**
```vb
Dim inv As Object
Set inv = New InventorySystem
inv.AddItem "Sword", 1, 150.0
inv.AddItem "Potion", 5, 25.0
Print inv.GetTotalValue()   ' → 275.0
```

```vb
Function AddItem(itemName As String, qty As Integer, unitPrice As Double) As Boolean
```

Adds a quantity of a named item at a given unit price.

If the item already exists, the quantity is increased and the
price is updated to the new value.

**Parameters:**

| Name | Description |
|------|-------------|
| `itemName` | The display name of the item (e.g. "Iron Sword") |
| `qty` | How many to add (must be > 0) |

**Returns:** True if the item was added, False if inventory is full
