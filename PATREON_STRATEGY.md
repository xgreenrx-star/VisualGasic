# Patreon Strategy for VisualGasic

## Setup Checklist

- [ ] Create Patreon account: https://www.patreon.com/creation
- [ ] Choose "Creator" profile type
- [ ] Set up tiers (see below)
- [ ] Add campaign video (60–90 seconds showing NES emulator demo or Code Navigator)
- [ ] Link from README.md, website, and GitHub Sponsors
- [ ] Post monthly progress updates (v6.0 milestones, bugs fixed, new features)

---

## Recommended Tier Structure

### **Tier 1: "BASIC Supporter" — $3/month**
- Early access to blog posts + dev updates
- Your name in monthly supporters list (on GitHub + website)
- Patreon-only Discord channel for announcements
- **Target:** 100–150 supporters = $300–450/month

**Pitch:** "Help keep VG development running. Get insider updates on v6.0 progress."

---

### **Tier 2: "Code Reviewer" — $15/month**
- Everything in Tier 1, plus:
- **Priority email support** (responds within 48h to VG questions)
- **Code review** — post VG scripts, get feedback before release
- **Exclusive tutorial content** — advanced VG patterns, optimization tips
- Access to pre-release builds (beta v5.3, v6.0-RC)
- **Target:** 15–25 supporters = $225–375/month

**Pitch:** "Get hands-on help with your VG projects + shape development priorities."

---

### **Tier 3: "Studio Partner" — $50/month**
- Everything in Tier 2, plus:
- **Priority feature requests** — propose VG language additions
- **Monthly 1-on-1 strategy call** (30 min) to discuss your game project
- **Custom consulting** — up to 4 hours/month at $0 cost (normally $150/hr)
- Logo on VG website + README (Partner section)
- **Early access to NES emulator** code + tutorials
- **Target:** 3–5 studios = $150–250/month

**Pitch:** "For game studios: get strategic guidance + custom VG consulting bundled."

---

### **Tier 4: "Gold Sponsor" — $250/month**
- Everything in Tier 3, plus:
- **Dedicated Slack channel** for your team (real-time support)
- **2 × 1-hour consulting calls/month**
- Logo prominently displayed on website homepage
- **Naming rights** — sponsor a VG feature (e.g., "Powered by [Studio] Async/Await")
- **Early access to v7.0 previews** (Python integration, 3D kit)
- **Target:** 0–2 sponsors = $0–500/month (aspirational, but realistic if one mid-size studio joins)

**Pitch:** "For serious VG studios: premium support + feature sponsorship."
