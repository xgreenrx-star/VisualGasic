## Known Pre-existing Issues (Not Regressions)

These issues existed before v2.2.2 and are NOT related to the bugfix:

1. **Mod Operator**: Returns left operand instead of remainder
2. **Select Case**: Case matching may not work correctly with ranges
3. **Global Variables in Subs**: Counter updates may not propagate correctly

## Bug Fix Verified

**Issue**: Double-clicking controls in Form Designer caused SIGSEGV crash
**Root Cause**: CodeHighlighter assigned to CodeEdit editing ScriptLanguageExtension scripts causes Godot 4.5.1 crash
**Fix**: Disabled custom GDScript syntax highlighting - C++ extension provides native highlighting
