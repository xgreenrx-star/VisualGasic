# Brotato Mini — Visual Gasic Port

Port of [brotato-mini](https://github.com/BLXCKBXXST/brotato-mini) (MIT) into Visual Gasic (`.vg`).

## Assets

- Kenney CC0 sprites/icons/tiles and sfx copied from upstream into `assets/`.
- Original game license: `LICENSE_BROTATO_MINI.txt`.

## Run

Open `samples/games/brotato_vg` in Godot 4.6 with Visual Gasic enabled (legacy: `projects/brotato_vg`), or:

```bash
scripts/ci_smoke.sh samples/games/brotato_vg
```
