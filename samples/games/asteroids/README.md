# Asteroids Clone

A classic Asteroids arcade game remake made with VisualGasic for Godot 4.5.

## How to Play

1. Open this folder as a Godot project
2. Run the main scene (main.tscn)

## Controls

- **Left/Right Arrows**: Rotate ship
- **Up Arrow**: Thrust forward
- **Space**: Shoot

## Gameplay

- Destroy all asteroids to advance to the next level
- Large asteroids split into medium asteroids
- Medium asteroids split into small asteroids
- Avoid colliding with asteroids
- You have 3 lives - Game Over when all lives are lost
- After taking damage, you're invulnerable for 3 seconds (ship blinks)
- Screen wraps around - objects that leave one edge appear on the opposite edge
- Press Space after Game Over to restart

## Scoring

- Large asteroid: 20 points
- Medium asteroid: 40 points
- Small asteroid: 60 points

## Features

- Classic Asteroids physics with momentum
- Progressive difficulty - more asteroids each level
- Screen wrapping gameplay
- Asteroid splitting mechanics
- Temporary invulnerability after hits
- Score and level tracking

Classic arcade action!
