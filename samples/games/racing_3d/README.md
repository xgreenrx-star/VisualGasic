# 3D Racing Game

A simple 3D racing game with an oval track made with VisualGasic for Godot 4.5.

## How to Play

1. Open this folder as a Godot project
2. Run the main scene (main.tscn)

## Controls

- **Up Arrow**: Accelerate
- **Down Arrow**: Brake/Reverse
- **Left/Right Arrows**: Steer

## Gameplay

- Complete 3 laps around the oval track
- Pass through checkpoints in order to complete each lap
- Stay between the inner and outer walls
- Hit walls to slow you down
- The camera follows your car from behind
- Complete the race as fast as possible
- Press Space after finishing to race again

## Track Layout

- Oval track with inner and outer boundaries
- 8 checkpoints around the track (invisible, but you must pass through them in order)
- Grass in the center, asphalt track, walls on both sides

## Features

- 3D graphics with camera following the car
- Realistic steering that's speed-dependent
- Physics-based acceleration and braking
- Lap counting and checkpoint system
- Race timer
- Track boundaries with collision detection
- Dynamic lighting

Race to beat your best time!
