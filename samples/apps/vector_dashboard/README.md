# Vector Dashboard

A small VisualGasic demo that shows vector drawing using the new Vector Graphics plugin.

## How to run

1. Open this folder as a Godot project.
2. Ensure the `addons/visual_gasic` symlink exists.
3. Run `main.tscn`.

## What it demonstrates

- A reusable `VectorCanvas` node
- Vector shape drawing with lines, rectangles, ellipses, and circles
- Live animated dashboard values
- Plugin-driven vector rendering using `vg_vector_api.gd`
