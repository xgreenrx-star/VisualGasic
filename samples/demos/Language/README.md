# Language

Core language feature demonstrations and tutorials.

## Overview

Focused tutorials on VisualGasic language fundamentals: data types, control flow, collections, functional programming, error handling, file I/O, date/time operations, and metaprogramming.

## Categories

| Category | Projects | Focus |
|----------|----------|-------|
| **Collections** | Array, Dictionary, Set operations | Data structure patterns and algorithms |
| **DateTime** | Datetime parsing, formatting, calculations | Date/time manipulation |
| **ErrorHandling** | Try/Catch, validation, custom errors | Exception handling patterns |
| **FileIO** | File reading/writing, JSON, CSV | Filesystem operations |
| **Functional** | Lambda, map/filter/reduce, pipes | Functional programming patterns |
| **Generics** | Type parametrization | Generic programming |
| **Lambdas** | Anonymous functions, closures | Lambda expressions |
| **Metaprogramming** | Reflection, type inspection | Runtime type information |
| **OOP** | Classes, inheritance, polymorphism | Object-oriented patterns |
| **Operators** | Custom operators, overloading | Operator definition and precedence |
| **Serialization** | JSON, XML, binary formats | Data serialization |
| **String** | Parsing, formatting, regex | String manipulation |
| **Tuples** | Tuple creation, unpacking | Tuple data structures |

## Quick Start

1. Browse category folder for your topic
2. Open `.vg` script in Godot editor
3. Run with F5 to see output in console
4. Review code comments and compare with tutorial docs

## Learning Progression

1. Start with **Collections** (arrays/dictionaries are fundamental)
2. Explore **String** and **DateTime** (practical everyday operations)
3. Study **OOP** (class design and architecture)
4. Advanced: **Functional**, **Metaprogramming** (advanced patterns)
5. Reference: **ErrorHandling**, **Serialization** (best practices)

## Notes

- Each example is standalone and can run independently
- Code is extensively commented for learners
- Compare implementations between categories to understand design patterns
- Refer to corpus examples for syntax validation
