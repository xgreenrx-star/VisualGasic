# 2D Games

Complete 2D game examples and prototypes.

## Overview

Full game implementations and mechanics tutorials for 2D development in VisualGasic, from classic arcade games to platformers and space shooters.

## Games

| Project | Type | Difficulty | Focus |
|---------|------|-----------|-------|
| **Pong** | Classic Arcade | Beginner | Basic collision, input handling, score tracking |
| **Pong_Advanced** | Arcade | Intermediate | Enhanced AI, sound effects, animations |
| **Platformer** | Platformer | Intermediate | Movement, jumping, gravity, platforms, hazards |
| **Platformer_Godot** | Platformer | Intermediate | Pure Godot physics integration variant |
| **Galactic_Defender** | Space Shooter | Advanced | Waves, power-ups, particles, boss encounters |

## Quick Start

1. Open a project subdirectory in Godot
2. Load the main scene (usually `main.tscn` or named after project)
3. Press F5 to play
4. Study the VisualGasic `.vg` scripts for game logic

## Learning Path

- Start: **Pong** (input, collision, simple AI)
- Next: **Platformer** (movement physics, level design)
- Advanced: **Galactic_Defender** (waves, patterns, state machines)

## Key Concepts Demonstrated

- Player input handling (keyboard, mouse)
- Collision detection and response
- Score and state management
- Sound and visual feedback
- Enemy AI and behavior trees
- Level progression and difficulty scaling

## Notes

- Each project is self-contained with its own scenes and assets
- Compatible with Godot 4.6+ and VisualGasic 5.2+
- Source code is thoroughly commented for educational purposes
