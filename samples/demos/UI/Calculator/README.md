# Calculator Demo

A classic four-function calculator with memory, written in VisualGasic.

## Features

- Four basic operations: + - × ÷
- Memory functions: MC, MR, M+, M-
- Percentage calculation
- Sign toggle (+/-)
- Decimal point support
- Full keyboard support
- Mouse/touch button clicks

## Keyboard Shortcuts

| Key | Function |
|-----|----------|
| 0-9 | Number input |
| + - * / | Operations |
| Enter/= | Calculate |
| . | Decimal point |
| % | Percent |
| Escape | Clear all |
| Backspace | Delete last digit |

## Features Demonstrated

- Event-driven input handling
- `Select Case` statements
- String manipulation (`Left`, `Right`, `Len`, `InStr`)
- Number formatting
- State management
- Custom drawing with colors
- Mouse and keyboard input

## How to Run

1. Open this folder in Godot 4.6.1+
2. Make sure the VisualGasic addon is enabled  
3. Run the project (F5)
