# UI

User interface design patterns and widget libraries.

## Overview

Complete UI system demonstrations: form builders, layout managers, theme systems, accessibility patterns, and Godot editor integration.

## Projects

UI projects showcase practical patterns for building robust, maintainable interfaces.

## Key Topics

- **Themeing** — Consistent visual styling, VB6-style color constants
- **Forms** — Data entry patterns, validation, submission
- **Dialogs** — Modal and modeless dialogs, user confirmation
- **Navigation** — Menu systems, tab containers, breadcrumb trails
- **Responsive Layout** — Anchor-based sizing, aspect ratio preservation
- **Accessibility** — Keyboard navigation, screen reader support, high contrast modes

## Best Practices

- Separate UI logic from game/app logic
- Use signals for UI state communication
- Design for keyboard-first interaction (consider console/mobile)
- Test with different resolutions and aspect ratios

## Notes

- Refer to `demo/custom_widgets/` for reusable scene components
- Godot 4.6+ provides native Layout engine; prefer native controls when possible
- VisualGasic UI demos integrate with Godot's Control system
