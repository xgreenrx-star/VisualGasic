# UI Demos

User interface and Godot IDE integration showcase.

## Overview

Interactive demonstrations of VisualGasic IDE tooling, UI patterns, and Godot editor integration features: Code Navigator, autocomplete, dot-completion, Property inspector, and Narcea AI Pair.

## Demos

| File | Feature |
|------|---------|
| `demo_chatbox.vg` | Chat UI with message list and input |
| `demo_compass.vg` | Rotating compass widget |
| `demo_confirm_dialog.vg` | Modal confirmation dialog |
| `demo_ammo_counter.vg` | Game HUD element (ammunition counter) |

## Running

1. Open the Godot editor with VisualGasic addon enabled
2. Load a `.vg` file into the Script editor
3. Press F5 to run or use Script Debugger

## Interactive Features

- **Code Navigator** — Press Ctrl+Shift+O (or via toolbar) to navigate code structure
- **Autocomplete** — Type and press Ctrl+Space for context-aware suggestions
- **Dot-Completion** — After object name and dot, VisualGasic suggests available properties/methods
- **Property Inspector** — Inspect class properties with type information
- **Narcea AI Pair** — Press Ctrl+Shift+A (or via toolbar) to ask AI for code suggestions

## Notes

- Requires Godot 4.6.1+ with VisualGasic 5.3+
- Features depend on addon configuration in project settings
